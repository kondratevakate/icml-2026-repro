DECISION (applied 2026-08-03): COMPACTION_WORSE on the clean pilot (CAffNet) ->
  Bundle 2 launched on ORIGINAL arm2 (NO compaction). Prompts regenerated to remove the
  compaction block.

CAVEAT: the original decision file was a watchdog crash-log (score_run.py path bug writing

  not recorded in the original decision file — added here.

NOTE ON "full_evidence_rate": several _score.json show 0.0 even when claims are verified.
  This field appears to key off mutation-test presence/evidence-boundary flags rather than
  raw verified count, so do not read full_evidence_rate=0.0 as "no evidence". Use
  per_claim_verdict + n_mutation_tests for the real quality signal.
